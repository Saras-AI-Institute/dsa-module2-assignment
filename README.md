# Module 2 Assignment: Selecting a Data Structure

When designing software applications, choosing the right data structure directly impacts **execution speed** (time complexity) and **memory usage** (space complexity). This assignment evaluates your ability to analyze requirements and select the most suitable data structure for given constraints.

---

## 🎯 Learning Objectives

- **Static vs Dynamic Allocation**: Compare fixed-size arrays with dynamic linked structures (Linked Lists) in terms of memory overhead and performance.
- **Architectural Matching**: Identify performance bottlenecks and choose between fast random access and flexible data growth.
- **Hybrid Data Configurations**: Understand how combining non-linear structures (Trees) with fast lookup structures (Hash Tables) can optimize real-world systems.
- Analyze trade-offs between time and space complexity.
