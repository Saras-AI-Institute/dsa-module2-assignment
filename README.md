# Module 2 Assignment: Selecting a Data Structure

When designing software applications, choosing the right data structure directly impacts execution speed (**time complexity**) and memory footprint (**space complexity**). This assignment evaluates your ability to pick and implement the correct structure under architectural constraints.

---

## 🎯 Learning Objectives
* **Static vs. Dynamic Allocation:** Observe how fixed-size blocks (Arrays) compare to dynamic, link-allocated objects (Linked Lists) regarding memory overhead.
* **Architectural Matching:** Identify performance bottlenecks to choose between fast access speeds and fluid data growth.
* **Hybrid Data Configurations:** Understand how combining non-linear structures (Trees) with relational mappings (Hash Tables) optimizes lookups in hierarchical systems.
